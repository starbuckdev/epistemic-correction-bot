// phase 1 — intake
⓪  adversarial input screen new in v0.2
Screen Before Processing
Checks for prompt injection, jailbreak patterns, and attempts to weaponize the steelman layer. Flags or rejects before any generation occurs. Non-negotiable for institutional credibility.
⚠ steelman layer is a potential laundering vector — screen first

①  user input
Raw Query
User submits proposition in first person. No framing constraints required.
↓
②  content router new in v0.2
Creative vs. Fact-Based Classification
Lightweight classifier determines pipeline path before expensive generation steps run.
→ fact-based route Empirical claims, predictions, policy analysis, risk assessments. Proceeds through full pipeline (layers 3–10).
→ creative route Poems, narratives, brainstorming, open-ended ideation. Divergence analysis is not meaningful. Routes to single-pass + primer filter.
mixed queries default to fact-based — creative framing flagged in output
↓
// phase 2 — analysis (fact-based path)
③  framing converter
First Person → Third Party
"I think X" → "A colleague proposes X"
Strips emotional investment. No editorializing.
bengio technique

④  claim decomposition new in v0.2
Break Complex Queries into Sub-Claims
Complex queries contain multiple independent propositions with different evidence bases. Without decomposition, synthesis cannot attribute divergence to specific sub-claims. Implicit claims are surfaced and made explicit before the steelman/critique split runs.
competing instances receive discrete sub-claims — not entangled arguments
competing instances — no shared context

Find the Case For
Strongest supporting evidence.
Charitable interpretation.
Assume competent advocates exist.
⑤b  llm b — critique
Find the Case Against
Weakest assumptions.
Disconfirming evidence.
Ways it could fail.
⚠ designed opposition — not duplicate runs
↓
⑥  synthesis layer
Divergence Analysis
Separates intersection (signal) from divergence (possible framing artifact or genuine uncertainty).
  • Genuine uncertainty → preserve and surface
  • Framing artifact → resolve without surfacing
  • Asymmetric evidence → do NOT average — flag and attribute
  • Value difference → flag explicitly as values-based, not evidence-based
risk: shared blind spots across 5a, 5b, and 6 may look like consensus
↓
// phase 3 — grounding
⑦  grounding classifier new in v0.2
External Truth Source Lookup
Identifies empirically resolvable claims after synthesis. Routes to external APIs before uncertainty labeling is applied. Contested empirical questions remain in genuine uncertainty category.
  • Calculator API — mathematical or quantitative claims
  • Web search / retrieval — factual lookups with authoritative sources
  • Domain databases — actuarial, legal, financial (deployment-configured)
grounding source bias risk — biased API produces false confidence
↓
⑧  confidence router new in v0.2
Cost Threshold Gate
High-confidence synthesis outputs with no empirical claims may skip the grounding call, reducing per-query cost. Addresses the 4–6 LLM call cost vulnerability. Threshold is configurable per deployment.
cost per query: 4–6 calls vs 1 baseline — value proposition must justify
↓
// phase 4 — presentation
⑨  presentation layer
Primer Filter
Applies epistemic standards: confidence levels, fact vs. inference, calibrated uncertainty. Shapes presentation only — cannot correct errors introduced at synthesis or grounding layers.
primer prompt applied here
↓
⑩  output
Epistemically Labeled Response
Explicit confidence levels. Divergence flags. What survived both framings vs. what appeared in only one. Provenance tags on all claims — layer of origin, confidence level, framing coverage. Grounding attribution where external APIs were called. Value-difference flags where normative disagreement was identified.
provenance tagging — new in v0.2
// known vulnerabilities
Shared Training Bias
All three generation calls (5a, 5b, 6) may converge on same wrong answer. Convergence ≠ truth. No architectural mitigation yet.
False Neutrality
Synthesis of two biased outputs ≠ unbiased. Flat earth: if both say flat, truth is not in the middle.
Synthesis Layer Bias
Synthesis LLM subject to same substrate bias. Misclassifying divergence type (e.g. value diff as genuine uncertainty) propagates errors downstream.
Claim Decomposition Error new
Incorrect split or merge of claims means steelman and critique operate on malformed inputs. Errors compound through synthesis.
Grounding Source Bias new
Routing a contested claim to a biased or low-quality external source produces false grounding confidence.
Primer Reach Limit
Cannot correct errors introduced at synthesis or raw output layers. Errors reaching layer 9 get presented with false epistemic confidence.
Cost Per Query
4–6 LLM calls vs 1. Partially addressed by confidence router in v0.2. Value proposition must justify unit economics.
No Feedback Loop v0.3
User-flagged errors have no correction intake path. Synthesis accuracy cannot improve over time. Planned for v0.3.
// target market
Actuaries, risk analysts, compliance
Fiduciary obligation = real demand for reliability. Confidence labels and divergence flags are directly actionable in risk-adjusted decision frameworks.
M&A due diligence, forensic audit
Adversarial information environments validate the tool. Clients already assume competing framings exist — the pipeline makes that explicit.
Investors, project planners
Quantifiable downstream cost of bad inputs. Calibrated uncertainty preferable to false precision in capital allocation decisions.
Journalists, researchers
Appetite exists, institutional incentive structures complex. Lower-priority segment for initial deployment.
